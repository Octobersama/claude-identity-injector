运行设置

控制插件是否处理匹配请求，以及与 CPA Cloak 的协作方式。

启用身份注入仅启用的规则会参与匹配；关闭后插件保留配置但不修改请求。
CPA Cloak 兼容模式兼容模式会保留 billing header 在 system[0]，识别 Cloak 已注入的身份并避免重复。
记录匹配日志在 CPA 主日志中记录规则命中、注入、跳过与错误事件，不记录凭证秘密。
固定注入内容
You are Claude Code, Anthropic's official CLI for Claude.
Cloak 兼容说明：兼容模式下，Cloak 的 billing header 保持在 system[0]，Claude Code 身份位于其后；Cloak 已包含该身份时插件不会重复注入。

匹配规则

按列表顺序匹配，首条命中的规则生效；留空的条件不参与限制。

匹配关系：启用的不同条件之间是“且（AND）”；同一条件中选择多个值是“或（OR）”。关闭的条件不参与匹配。
